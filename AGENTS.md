# Highway Hustlers agent guidance

For adding a hero bike, adding a rider, or changing a bike colour, read
[the hero-bike skill](.agents/skills/hh-hero-bikes/SKILL.md) first. It is plain
Markdown and works as an instruction guide even without a skills system.

Keep the existing hero design and interaction unless the user requests a redesign.
Do not commit, push, publish, or deploy just because a guide describes those steps;
those actions require a user request.
