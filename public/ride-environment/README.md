# Sunday game environment

Downloaded from the official Poly Haven asset manifests on 17 October 2026.
All three resources are [CC0](https://polyhaven.com/license).

- [Asphalt 02](https://polyhaven.com/a/asphalt_02): 1K diffuse and OpenGL normal maps.
- [Grass Path 2](https://polyhaven.com/a/grass_path_2): 1K diffuse map.
- [Small Rural Road 02](https://polyhaven.com/a/small_rural_road_02), Sergej Majboroda:
  1K HDR environment, used for reflections and illumination, not a fake Bhopal backdrop.

The sky, road, foliage, architecture, garage, dhaba and stop props are real-time game
geometry. The map preserves the existing example Bhopal–Kerwa loop, uniformly
condensed for a short ride. Scenery is interpreted, not a 1:1 Bhopal reconstruction.

Reacquire: `node scripts/fetch-ride-environment.mjs`.
